# pfUI VendorTweaks

A lightweight addon with 3 features:

![alt text](https://github.com/Seraphic8x2244/pfUI-VendorTweaks/blob/main/pfui-av.png?raw=true)


- Adds a custom list for autoselling items
- Adds a custom list for autodeleting items
- Adds a throttle on autoselling

## How to Use
- Requires pfUI: it's a module
- Drag and drop items to add to the whitelists
